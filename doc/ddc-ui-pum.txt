FREQUENTLY ASKED QUESTIONS (FAQ)                              *ddc-ui-pum-faq*

FAQ 1:                                                      |ddc-ui-pum-faq-1|
	I want to use ddc.vim's previewer in pum.vim's preview window.

FAQ 2:                                                      |ddc-ui-pum-faq-2|
	The popup menu does not work in |command-line-window|.

------------------------------------------------------------------------------
                                                            *ddc-ui-pum-faq-1*
Q: I want to use ddc.vim's previewer in pum.vim's preview window.

A: pum.vim does not use ddc.vim's previewer automatically.  Please set
|pum-option-previewer| to |ddc#get_previewer()| and enable
|pum-option-preview|. >vim

	call pum#set_option(#{
	      \   preview: v:true,
	      \   previewer: 'ddc#get_previewer',
	      \ })
<
                                                            *ddc-ui-pum-faq-2*
Q: The popup menu does not work in |command-line-window|.

A: It is the limitation of |command-line-window|.  See |pum-faq-3|.

NOTE: The problem is fixed in neovim 0.10+.  But |command-line-window| is
special buffer.  You need to enable |ddc-option-specialBufferCompletion|.

                                                            *ddc-ui-pum-faq-3*
Q: Do I need to add |PumCompleteDone| event for "ddc-source-lsp"?

A: No.  "ddc-source-lsp" source registers the event automatically.
